Transparencia del proceso
  • La plataforma usa autenticación institucional (cuenta @unsaac.edu.pe).
  • El servidor valida la elegibilidad de cada elector antes de aceptar un voto.
  • El sistema evita que un elector emita más de un voto.
  • No se almacenan contraseñas en ningún momento.
  • El código del frontend puede revisarse públicamente.
  • Las configuraciones privadas del servidor no se publican, por seguridad.
  • Ningún sistema informático garantiza seguridad absoluta.
  • El Comité Electoral conserva capacidad de revisión sobre el proceso.
